# Auto Photo Resize
A Project that automatically align eyes to (140, 292) and (310, 292) and Cut the Photo into 640 * 450

1. install python and download this repository.
2. pip install -r requirements.txt
3. put all the raw photo into ./input and run main.py
4. get processed photo in ./output

If you want to change the eyes location or photo size, you need to change some constant number in resize() in main.py

The example images are AI generated
